## What I Built

### 🔧 micro:bit Hardware Projects (Phase 1)

Six hardware projects using a BBC micro:bit and the Freenove Ultimate Starter Kit.

| Project | What It Does |
|---------|-------------|
| First Blink | Buttons, loops, and LED display |
| Candy Counter | Physical sales counter with display |
| Temperature Alert | Monitors candy storage — alerts when too hot |
| Motion Alarm | Security system using PIR sensor |
| Candy Dodge Game | Full game on the 5x5 LED grid |
| LCD Dashboard | Business stats on a 16x2 LCD display |

📁 [`microbit/`](./microbit/)

---

### 📊 Business System (Phase 2)

A complete business management system in Google Sheets, replacing a previous Excel workbook.

- Products tab with profit margin calculations
- Inventory tracking with automatic stock calculations
- Sales log
- Orders tab (filled automatically by the website)
- Dashboard with charts and key metrics

---

### 🌐 Candy Business Website (Phase 3)

A two-page website built from scratch with HTML, CSS, and JavaScript.

- Homepage with product catalog (dynamically generated from a JavaScript array)
- Order form that submits directly to Google Sheets via Google Apps Script
- Fully responsive — works on phones
- Deployed with GitHub Pages

📁 [`website/`](./website/)

**Key things I figured out:**
- How CSS Flexbox/Grid layout works
- How JavaScript DOM manipulation works
- How to send data from a browser to a server using `fetch()`
- How to connect a website to Google Sheets

---

### 🎮 Candy Catcher Game (Bonus)

A browser-based game built entirely in JavaScript using HTML Canvas.

- Falling candy you catch with a basket
- Mouse and keyboard controls
- Rare items, bombs (don't catch those!)
- Score tracking with high score
- Speed increases as you score more

📁 [`game/`](./game/)

**What I learned building it:** How game loops work. How to detect collisions. How to use `requestAnimationFrame()` for smooth animation.
