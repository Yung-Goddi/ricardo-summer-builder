## micro:bit

| Resource | What It's For |
|----------|--------------|
| `microbit-micropython.readthedocs.io` | Official MicroPython docs for micro:bit |
| `makecode.microbit.org` | Block editor (good for quick experiments) |
| `codewith.mu` | Mu Editor download |
| `microbit.org/projects` | Official project ideas |

**Most useful micro:bit Python functions to know:**
- `display.show()`, `display.scroll()`
- `temperature()`, `accelerometer.get_x()`
- `button_a.was_pressed()`, `button_b.is_pressed()`
- `pin0.read_digital()`, `pin0.write_digital()`
- `i2c.write()`, `i2c.read()`
- `sleep()`, `running_time()`

## When You're Looking Something Up

Search tips:
- `MDN [what you want]` — finds MDN documentation for HTML/CSS/JS
- `python docs [function name]` — finds official Python docs
- `microbit python [what you need]` — finds micro:bit specific help
