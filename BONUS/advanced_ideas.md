# Advanced Ideas

## What You Could Build After This Summer

---

You've built a real foundation this summer. Here's where it could go next.

These aren't for right now. They're for September and beyond — when you want to keep building.

---

## Level Up the Business Website

**Google Analytics** — Add a free analytics tracker to your website to see how many people visit, where they come from, what they click on. Turns your site into a data source.

**Email notifications** — When an order comes in, trigger an automatic email to yourself via Gmail and Google Apps Script.

**Product photos** — Add real photos to each product card. Learn how to store images in GitHub and reference them in HTML.

**Customer accounts** — Build a simple login system so returning customers can see their order history. (This is advanced — involves backend programming.)

---

## Level Up the Business System

**Automated inventory updates** — When someone orders candy, automatically decrease the inventory count. (Connect Orders tab → Inventory tab via Apps Script.)

**Profit tracking** — A monthly profit and loss statement that calculates revenue, cost of goods, and net profit automatically.

**Goal tracker** — Set a weekly revenue goal and have the dashboard show a progress bar toward that goal.

---

## Level Up the micro:bit Projects

**Radio network** — If you can get more micro:bits, build a system where the candy counter micro:bit sends sales data wirelessly to the LCD display micro:bit.

**Web Bluetooth** — Modern browsers can connect to micro:bit via Bluetooth. You could send sensor data directly to your website in real time.

**Data logging** — Write micro:bit sensor readings to a file, import them into Google Sheets, and chart them over time.

---

## New Technologies to Explore

**React** — After you're solid with vanilla JavaScript, React is the most popular tool for building bigger web apps.

**Python Flask** — Build a simple web server with Python. This lets you run code on the server when someone visits your website, rather than just serving HTML files.

**SQLite** — A real database stored in a file. Better than CSV for storing business data. Python has it built in.

**Node.js** — JavaScript that runs on the server, not just in the browser. Huge ecosystem.

**APIs** — Connect your projects to external services. Weather data, maps, payment processing, social media.

---

## Bigger Projects

**A real mobile app** — React Native lets you build iOS and Android apps using JavaScript. Your candy ordering system, but as an app on someone's phone.

**A point-of-sale system** — A tablet app that you use when selling candy in person. Tap a product, tap quantity, show the total. Log the sale. Much better than a paper notepad.

**Inventory automation** — Use a barcode scanner (they're cheap USB devices) to scan products in and out of inventory. The scanner types the barcode number into whatever is focused — you just need a Python script to look up that barcode.

**Automated reordering** — When inventory drops below the reorder point, automatically draft an order template or notify you with exactly what to buy and how much it'll cost.

## The Real Skill Under All of This

Here's what this summer was actually about:

You practiced **breaking problems down into smaller pieces**.

Every project started as one big idea and became:
- A list of functions
- A list of variables
- A list of things to wire up
- A list of things to test

That skill — decomposing a big problem into small solvable pieces — works everywhere. It works in programming, in business, in life.

You practiced it dozens of times this summer.

That's what you actually built.
