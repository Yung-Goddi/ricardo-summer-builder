# Ricardo's Summer Builder Program v1.0

## Read This First

---

Hey Ricardo. And hello to whoever helped Ricardo find this.

This folder is a complete summer program built around one idea:

**By the end of this summer, you will believe — because you have *proof* — that you can build real things with technology.**

Not toy projects. Not school exercises.

Real things. Things that work. Things you can show people.
