# Session Startup Checklist

## Do This at the Start of Every Coding Session

This takes 2 minutes. It saves 20 minutes of confusion.

---

- [ ] **Open `WORK_LOG.md` first.** Read the **⭐ START HERE NEXT TIME** box at the top.
  - That box tells you what you were working on and the very next thing to do.
  - This is why you never have to remember "where was I?" — you wrote it down last time.
- [ ] **Open VS Code** and your project folder
- [ ] **Test that things still work** — run your code from last session before changing anything
- [ ] If doing hardware: **connect micro:bit**, open Mu Editor
- [ ] **Now go build** the next thing from your ⭐ box.

---

## End of Session

**Before you close the laptop, go back to `WORK_LOG.md`:**

- [ ] **Update the ⭐ START HERE NEXT TIME box** so Future You knows exactly where to pick up
- [ ] **Add today's Session block** — what you got done, where you stopped, any question or idea
- [ ] **Does the thing you set out to build actually work?**
- [ ] Push everything to GitHub:

```bash
git add . && git commit -m "Session: what I built" && git push
```

---

**The whole routine in one sentence:** Open `WORK_LOG.md` → build → update `WORK_LOG.md` → push.
