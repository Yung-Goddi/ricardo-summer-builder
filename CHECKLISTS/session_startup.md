# Session Startup Checklist

## Do This at the Start of Every Coding Session

This takes 2 minutes. It saves 20 minutes of confusion.

---

- [ ] **Open VS Code** and your project folder
- [ ] **Review last session** — what were you building? Where did you leave off?
  - Check your journal from last time
  - Look at the last few lines of code you wrote
  - Re-read any TODO comments you left for yourself
- [ ] **Set one goal** for this session — write it down
  - Example: "Get the order form to validate that name field isn't empty"
  - Not: "Work on the website" (too vague)
- [ ] **Test that things still work** — run your code from last session before changing anything
- [ ] If doing hardware: **connect micro:bit**, open Mu Editor

---

## End of Session

- [ ] **Does the thing you set out to build actually work?**
- [ ] `git add . && git commit -m "Session: what I built" && git push`
- [ ] **Quick journal note** (3 sentences is enough between full weekly entries)
