# Before Asking Dad

## Try All of These First

---

Being able to get yourself unstuck is the most important skill you can learn this summer. More important than any specific programming concept.

Before you ask Dad (or anyone else) for help, go through this checklist. Seriously — all of it.

---

## The Checklist

### Step 1: Read the Error Message

- [ ] Did you actually read the error message, word by word?
- [ ] What line number does the error point to?
- [ ] Does the error message say WHAT went wrong? (Example: "NameError: name 'sales_count' is not defined" = you used a variable before defining it)

**Read errors like clues, not just red text to ignore.**

---

### Step 2: Look at the Code

- [ ] Go to the exact line number the error mentions
- [ ] Read the 5 lines above it and the 5 lines below it
- [ ] Is there a typo? A missing colon? Wrong indentation? A misspelled variable?
- [ ] Did you recently change something? What did you change?

---

### Step 3: Check `TROUBLESHOOTING/common_errors.md`

- [ ] Is this error in the common errors list?
- [ ] If yes, follow the solution there

---

### Step 4: Search Online

- [ ] Copy the exact error message
- [ ] Paste it into Google (or your search engine)
- [ ] Add "micro:bit Python" or "JavaScript" or "Google Sheets" to help narrow it down
- [ ] Read at least 2 results before deciding the answer isn't there
- [ ] Check Stack Overflow results — they're almost always useful

---

### Step 5: Ask AI

- [ ] Ask AI what the error means and what might cause it
- [ ] Share the relevant code (not 200 lines — just the part that's broken)
- [ ] Ask AI to EXPLAIN the solution, not just give it to you
- [ ] Make sure you understand the fix before you use it (can you explain it in your own words?)

---

### Step 6: Try Something

- [ ] Did you actually try a solution? (Not just read about it)
- [ ] What happened when you tried it?
- [ ] If it didn't work, what changed? Did the error message change?
- [ ] Try a different approach
- [ ] Try simplifying — remove code until the error goes away, then add back piece by piece

---

### Step 7: Document What You Tried

Before asking for help, write down:

1. What I was trying to do:
2. The exact error message:
3. What I tried (at least 3 things):
4. What happened when I tried them:
5. My best guess at what's wrong:

Writing this down often reveals the answer. Seriously — the act of explaining the problem clearly often makes you realize the solution.

---

## If You've Done ALL of the Above and Still Stuck

Then ask. For real. You've earned it.

When you ask, share:
- The error message
- The relevant code
- What you already tried

This makes the conversation much faster and more useful.

---

## Why This Matters

When you're a professional developer, you won't have someone to call every time you get stuck. You'll have Stack Overflow, documentation, AI, and your own brain.

This checklist is training that skill.

The programmers who get the best results are the ones who can figure things out themselves. Not the ones who always know the answer — the ones who always find it.
