# Weekly Checklist

## What to Do Every Week

---

### Monday (or First Session of the Week)

- [ ] Open your progress tracker (`TRACKER/progress.md`) and see where you left off
- [ ] Decide what you're working on this session — be specific ("finish the order form validation" not "work on the website")
- [ ] Open VS Code and your project files
- [ ] Make sure your micro:bit is connected (if doing hardware)

---

### During the Week (Each Session)

- [ ] Start where you left off — don't start something new if something is unfinished
- [ ] When you get stuck, try for at least 15 minutes before asking for help
- [ ] Write down any error messages in your journal (even if you solve them)
- [ ] Every time you get something working, save and commit:
  ```bash
  git add .
  git commit -m "What I just built"
  git push
  ```
- [ ] End every session with something visible — a working thing, not just written code

---

### Friday (or Last Session of the Week)

- [ ] Make sure everything you built this week is pushed to GitHub
- [ ] Update your progress tracker (`TRACKER/progress.md`)
- [ ] Write your journal entry (`JOURNAL/weekN.md`)
- [ ] Record a quick demo video (see `PORTFOLIO/screenshot_guide.md`)
- [ ] Check off completed items in progress tracker

---

### End of Week Questions

Ask yourself these before closing the laptop:

1. What did I finish this week?
2. What did I NOT finish? Why?
3. Was there a moment this week where I figured something out myself?
4. What am I building next week?

---

### Before a Long Break (vacation, camp, etc.)

- [ ] Push everything to GitHub
- [ ] Write a longer journal entry covering what you were working on and where you left off
- [ ] Add a note to your progress tracker with "PAUSED — returning [date]"
