# Setup Guide

## Get Everything Ready Before You Start Building

---

Do this setup ONCE at the beginning of the summer. If you skip it, things will break later and you'll spend hours figuring out why.

This will take about 60–90 minutes. Put on music. It's worth it.

---

- [ ] Step 4 — Google Account check
- [ ] Step 5 — Create your GitHub repository
- [ ] Step 6 — Test everything works

## Step 1 — VS Code

VS Code is where you write all your code.

**If you don't have it yet:**
1. Go to `code.visualstudio.com`
2. Download the version for your operating system
3. Install it (all default settings are fine)

**Extensions to install inside VS Code:**
1. Open VS Code
2. Click the icon on the left sidebar that looks like four squares (Extensions)
3. Search and install each of these:
   - `Python` (by Microsoft)
   - `Prettier - Code formatter` (by Prettier)
   - `GitLens` (by GitKraken)

Full details: `INSTALLATION/vscode_setup.md`

---

## Step 2 — GitHub

GitHub is where all your code lives in the cloud. Think of it like Google Drive, but for code.

**If you don't have an account:**
1. Go to `github.com`
2. Click "Sign up"
3. Use a professional username (not xXgamerXx). Something like `ricardo-builds` or your real name.
4. Use your Google email

Full details: `INSTALLATION/github_setup.md`

## Step 3 — micro:bit Setup

## Step 4 — Google Account Check

Make sure you can log into:
- Google Drive

You'll use all three. If you use a school Google account, check that Google Sheets is enabled — sometimes schools lock this.

---

## Step 5 — Create Your GitHub Repository

This is where EVERYTHING you build this summer will live.

1. Log into GitHub
2. Click the green "New" button
3. Repository name: `candy-builder-2026`
4. Description: `My summer build projects — candy business tech + hardware + web`
5. Set it to **Public** (so it can be your portfolio)
6. Check "Add a README file"
7. Click "Create repository"

Then clone it to your laptop:
1. Open VS Code
2. Press `Ctrl+Shift+P` (or `Cmd+Shift+P` on Mac)
3. Type "Git: Clone" and press Enter
4. Paste your repository URL (from GitHub, click the green "Code" button, copy the HTTPS link)
5. Choose where to save it (Desktop or Documents is fine)
6. Open the folder when VS Code asks

---

## Step 6 — Test Everything

### Test VS Code:
1. Open VS Code
2. Create a new file called `test.py`
3. Type: `print("Ricardo is ready to build!")`
4. Press F5 to run it
5. You should see the message appear at the bottom

### Test GitHub:
1. In VS Code, open the Source Control panel (left sidebar, looks like a branch)
2. You should see your repository connected

### Test micro:bit:
Follow `INSTALLATION/microbit_setup.md` — there's a test program at the end.
