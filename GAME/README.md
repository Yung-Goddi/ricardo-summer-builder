# The Browser Game

## Candy Catcher — A Game You Build and Play

**Time:** 2–3 hours
**Difficulty:** Intermediate
**Tech:** HTML + JavaScript (runs in your browser, no setup needed)

---

## What This Is

You already built a game on the micro:bit (the dodge game). This is a bigger, more polished version in the browser — with score tracking, increasing difficulty, sound effects (optional), and a proper game-over screen.

**Candy Catcher:**
- Candy falls from the sky
- You control a basket at the bottom
- Move the basket left/right with arrow keys or your mouse
- Catch the candy to score points
- If you miss too many, game over
- Speed increases as your score goes up

This is a real browser game. You can send the link to friends and they can play it.

---

## The Files

- `index.html` — The game page
- `game.js` — All the game logic

Open `index.html` in your browser to play.
